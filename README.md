# 🏥 Clinic Management System (CMS)

A modern, enterprise-ready Electronic Medical Record (EMR) and Clinic Management Dashboard built with **.NET 10 Blazor WebAssembly** and **Entity Framework Core**.

## 🚀 Quick Start
* Ensure you have the [.NET 10 SDK](https://dotnet.microsoft.com/) installed.
* Run `Update-Database` in the Package Manager Console to build the SQL tables.
* Press `Ctrl + F5` to launch the application.
